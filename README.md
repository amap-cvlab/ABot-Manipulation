# ABot Project Pages

Project pages for **ABot-M0** and **ABot-M0.5**.

## Structure

- [`index.html`](./index.html) — ABot-M0.5 project page (default homepage)
- [`m0.5/static/`](./m0.5/static/) — ABot-M0.5 assets
- [`m0/`](./m0/) — ABot-M0 project page and assets

Use the top-right **M0 | M0.5** switcher to jump between versions.
